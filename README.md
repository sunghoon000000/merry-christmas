# 설야 — 편지로 짓는 겨울 마을

내 마을 링크를 보내면 친구들이 편지를 담은 집을 하나씩 지어 주는 크리스마스 사이트예요.
편지는 마을 주인만, 12월 25일 0시(한국 시간)부터 열어 볼 수 있어요.

사이트 주소: https://sunghoon000000.github.io/merry-christmas/

## 들어 있는 것

- 마을 만들기, 링크 공유, 집 지어 주기(오두막·빵집·종탑·눈사람 등 10가지 중 하나 + 편지)
- 마을 레벨업: 편지 3·7·12·20·30통마다 전구, 가로등 길, 얼음 연못, 오로라, 산타 썰매
- 매일 불 밝히기: 연속 3일 굴뚝 연기, 7일 창문 불빛, 14일 하늘 등불
- 12월 25일 개봉: 창문에 하나씩 불이 켜지고 편지 열기, 올해의 마을 카드
- 크리스마스 운세, 어드벤트 캘린더
- 관리 코드로 다른 기기에서 내 마을 불러오기

## 설정

1. Firebase 프로젝트에서 **Authentication → 익명 로그인**을 켜요.
2. **Firestore Database**를 만들고, **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 게시해요.
3. `index.html`의 `FIREBASE_CONFIG`를 Firebase 웹 앱 설정 객체로 바꿔요. `null`이면 이 기기에만 저장되는 미리보기 모드로 동작해요.
