# 우리들의 크리스마스

내 트리를 만들어 링크를 공유하면 친구들이 장식과 편지를 달아 주는 크리스마스 사이트예요.
편지는 트리 주인만 읽을 수 있고, '크리스마스에 열기'로 만든 트리는 12월 25일 0시(한국 시간)부터 열려요.

사이트 주소: https://sunghoon000000.github.io/merry-christmas/

## 들어 있는 것

- 크리스마스 카운트다운
- 트리 편지: 내 트리 만들기, 링크 공유, 편지 달기, 관리 코드로 다른 기기에서 불러오기
- 모였을 때 놀거리: 마니또 뽑기, 파티 카드(토크/미션/벌칙)
- 어드벤트 캘린더, 크리스마스 카드 쓰기

## 설정

1. Firebase 프로젝트에서 **Authentication → 익명 로그인**을 켜요.
2. **Firestore Database**를 만들고, **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 게시해요.
3. `index.html`의 `const FIREBASE_CONFIG = null;`을 Firebase 웹 앱 설정 객체로 바꿔요.

`FIREBASE_CONFIG`가 비어 있으면 이 기기에만 저장되는 미리보기 모드로 동작해요.
